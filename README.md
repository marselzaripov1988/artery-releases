# Выпуски artrd — узел сети Artery

Здесь лежат собранные двоичные файлы узла и их контрольные суммы. Ничего
кроме них: исходники, стенды и исследовательские материалы — в рабочих
репозиториях.

## Как проверить скачанное

```sh
sha256sum -c artrd-<версия>-linux-amd64.sha256
chmod +x artrd-<версия>-linux-amd64
./artrd-<версия>-linux-amd64 version --long
```

Ответ должен содержать ту же версию и тот же коммит, что указаны в
описании выпуска. Исполняемый бит теряется при скачивании через Windows,
поэтому `chmod +x` обязателен.

## О сборках

Файлы **статические** (ELF 64-bit, x86-64, CGO отключён): внешних
библиотек не требуют и запускаются на любом linux/amd64 независимо от
дистрибутива. Версия и коммит проштампованы в двоичный файл, а проверки
встроены в саму сборку и не дают выпустить файл без отметок.
